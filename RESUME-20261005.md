  when its code moved or when it ran a client with the caches on). It
  blocks a 10× faster OpenBIOS CD boot, and OS kernels may meet it too.
- **Decisions:**
  1. **L2 TLB On by default?** The core's MMU has a 128-entry
     second-level TLB, off unless the OSD option Advanced → L2TLB is On.
     With it On (and OpenBIOS now setting the bit on all CPUs), Solaris
     boots in 296 s instead of 344 and CPU-bound work runs ~28 % faster; a
     35-minute 3-CPU stress was clean. But Grabulosaure's README says
     NeXTSTEP is not compatible with it. On by default (NeXTSTEP users
     switch it off), or Off as now?
  2. **Sun POST:** it stops at the MMU TLB bit-pattern test, which needs
     SuperSPARC's 64-entry TLB through ASI 6 (the core has 4+4 entries).
     Passing it means a diagnostic TLB image per CPU plus the flush tests'
     demap rules (my rough estimate: a few hundred ALMs per CPU, with
     ~4,600 ALMs free on the SS20), and POST has more tests after it.
     Worth a Fable task, or leave POST for later?
  3. **A larger first-level TLB?** The TLBs have 4 entries each; a miss
     costs ~38 cycles (~27 with the L2 TLB). More entries would speed up
     everything, but cost ALMs and maybe timing on a device that is 89 %
     full (this session's fits: seed 1 failed to route, seed 2 met the
     core clock by 0.017 ns). A Fable task to measure and try?

## Gotchas learned this session

- **bash `until` loops return the body's last status**: a wait function
  built on one returns 1 after waiting unless it ends with `return 0`.
- **`pkill -f PATTERN` matches its own shell** when the pattern is on its
  command line (it killed this session's shells twice, and another job):
  wait on PIDs (`while kill -0 PID`), or put a bracket in the pattern
  (`quartu[s]`).
- **`setopt.sh` starts from the defaults each time**: options not given
  go back to their defaults (pass every option a test needs).
- **OpenBIOS counts in hex** at `ok`; type `decimal` first. Its echo of a
  typed line and the output share a line: put markers after a `cr`.
- **OpenBIOS's "Not a bootable ELF image"** is only the ELF probe; the
  a.out loader runs next.
- `ttyx.sh` cannot type a single quote (ssh quoting): type programs
  through `cat > FILE <<\E` here-documents. Solaris 8's `grep` has no
  `-E` (`egrep`).
- **The Solaris image's network interface is `le1` under OpenBIOS** (its
  `path_to_inst` comes from QEMU).
- The simulation of OpenBIOS waits 3 s of machine time (165 M cycles)
  without `--nvram`.
- After a failed fit, `output_files/` still holds the previous rbf: check
  `build.sh`'s exit status before copying it anywhere.
- In an assembler test, never put a `set` of a value > 4095 in a delay
  slot (it is two instructions); V8 alternate-space stores take only
  register+register addresses.
