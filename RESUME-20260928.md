## Gotchas learned this session

- **Quartus.**
  - Only one flow at a time.
  - Don't edit the `.qsf` during a build.
  - `build.sh` writes `build_id.v` itself, because running
    `sys/build_id.tcl` standalone inlined 300 pin lines into the qsf.
  - The fitter takes about 20-30 min now that the clock groups are right.
    Without them it took 1.5 h.
- **Serial.** The core runs ttya at a fixed 115200 8N1 whatever the OS
  programs. `console.sh` handles it.
- **Screenshots.** mrext is on the MiSTer: `curl -X POST
  http://192.168.99.92:8182/api/screenshots`, then fetch the newest file
  from `/media/fat/screenshots/SunSparcStation/`.
- **QEMU installs.**
  - Use `-nographic`; with a display, the real OBP moves its console to
    the invisible screen.
  - QEMU's OpenBIOS can't boot the NetBSD CD (the Sun label counts 512-byte
    blocks on a 2048-byte CD); the real SS5 PROM can.
  - Solaris Web Start crashes on an unlabelled disk; label it with `format`
    → type 18 first.
- **Driving consoles from scripts.**
  - Wait for a marker that the echoed command line cannot contain (for
    example `echo X-$((1+1))`, then match `X-2` as a whole line).
  - Never `pkill -f` a pattern that also appears in your own command line.
