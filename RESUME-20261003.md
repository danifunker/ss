## Gotchas learned this session

- **CDE / screen console:** Solaris prints its screen console through the
  PROM (romvec devwrite/putstr -> OpenBIOS Forth). OpenBIOS is not
  re-entrant; on 3 CPUs it corrupted itself and the kernel (fixed by the
  romvec lock, `d27d997`). With `console=serial` OpenBIOS is never called.
  `Xsun` and `dtlogin` themselves work; `dtconfig -d/-e` turns CDE off/on.
- **Solaris kernel symbols are stripped of statics:** `panicsys` was the
  idle loop's nearest global; check `panicstr` (0 = no panic) before
  calling it a panic (`pcdump -m f0258584,1`).
- **ts_esp OUT-phase data** (MSG OUT, COMMAND, DATA OUT) is valid the cycle
  *after* REQ&ACK (its DMA byte is registered); IN-phase data is taken in
  the ACK cycle.
- **OpenBIOS's do_command** leaves a target in STATUS without ICCS for
  commands with no data; a real 53C9x (and QEMU) rejects the next SELATN.
  scsitest mode 0 is core-only (`-DSCSI_NO_MODE0` for QEMU).
- **Quartus vs GHDL:** a variable-index slice in a VHDL function passes
  GHDL but fails Quartus (`b8`); `to_std_logic(...)` as a port actual is
  rejected by GHDL (use a signal).
- **Self-matching kills again:** `pkill -f scsitest.rom` killed its own
  shell; always bracket a character (`'scsitest[.]rom'`).
- **Auto-mode classifier:** copying code from another local repo was
  blocked as "untrusted code integration" (the user then decided against
  the cache anyway). Ask the user before pulling code from other repos.
