## Gotchas learned this session

- **`pgrep -f`/`pkill -f` match their own command line**, and so does any
  shell whose command line contains the pattern: a waiter loop
  `until ! pgrep -f quartus_fit` never ended and made `build.sh` refuse to
  start (it looks for running Quartus the same way); a `pgrep -f "[x]yz"`
  in a command that also runs `xyz` killed its own shell. Wait on PIDs,
  or keep the pattern out of the command line that runs it.
- **Never edit a script while bash runs it** (bash reads scripts as it
  goes; an in-place rewrite changes what it reads next). Run snapshot
  copies for long board batches (`scripts/common.sh` cds to the repository
  from its own path: a copy elsewhere needs that line changed).
- **pcdump biases PC samples:** switching ttya to the debug link stalls the
  ESCC's transmitter, so a CPU that prints is caught in `uemit?`.
- **The MiSTer's Python has no `termios.TIOCSBRK`:** send a BREAK with
  `termios.tcsendbreak(fd, 0)`.
- **mrext's keyboard-raw call only taps keys:** for chords and held keys use
  `scripts/board/uinput_keys.py` on the MiSTer (a uinput keyboard Main reads
  like a USB one).
- **In SPARC assembler, a second argument set after the `call`** is set
  after the callee ran: put `mov X, %o1` before the `call`, `%o0` in the
  delay slot (brktest's first version read garbage).
- **The Sun OBP's `ok` is hex:** `1000000` is 16 MB; OpenBIOS also counts
  in hex at `ok`.
