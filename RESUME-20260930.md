## Gotchas learned this session

- **One reader on /dev/ttyS1 at a time**: a second `cat` steals bytes (garbled
  logs). The MiSTer's busybox has no `pkill`/`pgrep`: use `ps | awk | xargs
  kill` (hwtest.sh does).
- **Never trust ROM copies on the MiSTer**: a stale `cputest-ss5.rom` produced
  false "failures" today. `hwtest.sh` pushes from `tests/cpu/out`.
- **Quartus rewrites `SunSparcStation.qpf` and the revision `.qsf`**: `git
  checkout -- ` them after every build. `build.sh` refuses a second flow;
  coordinate with Fable (message it before taking Quartus).
- **Simulation**: ~50-60 kHz. Don't rebuild `sim/obj_ss5` while a run uses it;
  `SIM_OBJ=dir sim/build.sh 5` builds elsewhere. `--ddr-log-from C` shows
  where code runs (PROM fetches at core address `0x1D0xxxxx`). The harness
  preloads the ROM; `--full-download --dl-gap N` tests the real loader.
- **Direct SD is gone**: its inputs are tied idle-high in `ss_core`; the
  floating read-back made OpenBIOS hang at random earlier today.
- **ESCC/keyboard**: the core couples ESCC TX readiness to the emulated
  device; a device that refuses input deadlocks a polling host.
- **Solaris 8 shell is Bourne**: no `$(( ))`; hwtest uses `echo X-""42`.
