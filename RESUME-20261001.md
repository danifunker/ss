## Gotchas learned this session

- `pkill -f PATTERN` kills the shell running it when its own command line
  contains PATTERN; kill by PID (`pgrep -af 'x[.]sh' | ...`) in a separate
  command, or build the pattern from a variable (`p=foo; pkill -f "$p"`);
  the same self-match makes `until ! pgrep -f ...` loops wait forever.
- LLVM assembles 13-bit immediates out of range silently (`add %o1, 0x1000`
  → `-0x1000`, `cmp %l1, 0x4000` → `cmp %l1, 0`); a two-instruction `set`
  in a delay slot runs only its `sethi`.
- The SS5's D-cache is virtually tagged: a test that remaps a VA must flush
  the line (ASI 0x10) or it reads the old page from the cache.
- Three Verilator runs at once bring the box to 20 kHz each; one SS20 suite
  run is 20-40 min, the POST reaches its MMU tests after ~130M cycles.
- Two readers on `/dev/ttyS1` (a capture left running) split the bytes and
  look like a UART bug. `hwtest.sh` kills stray `cat`s; a killed hwtest
  can leave one.
- OpenBIOS polls ttya: keys typed while it prints are lost. Wait for the
  prompt; type a character at a time (15 ms).
- Under the Sun OBP the console is the screen and keyboard (the emulated
  keyboard is always present): screenshots via mrext, typing via
  `scripts/kbtype.sh`.
- `pcdump` switches ttya to the debug link (BREAK + '3') and back ('4');
  stop any console capture first.
