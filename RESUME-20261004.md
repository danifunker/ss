## Gotchas learned this session

- **The ESP must interrupt on the target's next REQ, not at DMA count-out**
  (`04b59bd`): a slow target (the new engine writing through Main) made
  NetBSD time out on its first write. `sim --sd-latency 20000` reproduces
  such timing; the default 40 cycles hides it.
- **The assemblers wrap out-of-range 13-bit immediates silently** (LLVM 18
  and GNU as): `tests/cpu/check_imm.py` runs in `build.py`.
- **OpenBIOS's DMA buffer must stay one page** (dvma_alloc); a 32 KB
  buffer corrupted OpenBIOS's memory. Its deblocker reads 512 bytes per
  call unless the device has `max-transfer`.
- **OpenBIOS takes ~80-character input lines**, and drops typed characters
  while it prints: type slowly (`TTYX_DELAY=60000`), short lines.
- **pcdump talks over ttya**: stop the console capture first
  (`scratch/stopcap.sh`), or it hangs.
- **Self-matching waits**: never `until ! pgrep -f 'x[.]sh'` from a job
  whose own command line contains `x.sh`; chain runs in one job.
- **Bash reads scripts as it runs them**: do not edit a script while a
  run of it is in progress.
